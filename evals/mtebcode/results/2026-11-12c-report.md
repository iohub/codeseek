## 5. Reproduction Commands

```bash
# 在仓库根目录执行；所有产物都落在 --workdir 里
cd evals/mtebcode

# 0) 离线自检：nDCG 数值 / 容错解析 / doc_id 反查 / 端到端报告（不联网、不需要二进制）
python3 -m mtebcode_eval selftest

# 1) 抓取数据集 + 抽样 query + 池化 corpus + 物化（本批次真实参数）
python3 -m mtebcode_eval prepare \
  --workdir /tmp/mtebcode-short \
  --tasks CodeEditSearchRetrieval-go,CodeEditSearchRetrieval-javascript,CodeEditSearchRetrieval-python,CosQA \
  --limit-queries 20 \
  --corpus-size 300 \
  --seed 42 \
  --parquet-cache ~/.cache/huggingface/hub \
  --proxy http://127.0.0.1:7897
#   ↑ --proxy 请替换成你自己的本地代理；国内直连 datasets-server 通常会被 429 限流。
#   ↑ --parquet-cache 让本地 HF 缓存命中的 (config, split) 直接读盘、不发网络请求；
#     确实无缓存时可省略该参数（或改用 --cache-only 做纯离线复现）。

# 2) 执行检索并出报告（--force 忽略已有 raw 结果；本批次 search_limit / k 如下）
python3 -m mtebcode_eval run \
  --workdir /tmp/mtebcode-short \
  --limit 20 \
  --k 10 \
  --concurrency 4

# 3) 只重算指标（不重跑检索；换 k 只需改这里，便于做 k 敏感性分析）
python3 -m mtebcode_eval score \
  --workdir /tmp/mtebcode-short \
  --limit 20 \
  --k 10
```
